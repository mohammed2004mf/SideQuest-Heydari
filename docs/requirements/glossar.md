# Glossar

Das Glossar legt Begriffe eindeutig fest, damit Anforderungen nicht mehrdeutig sind. Begriffe werden in allen Artefakten genau so verwendet.

| Begriff | Definition |
|---|---|
| **Achievement** | Auszeichnung, die ein Spieler freischaltet, sobald eine festgelegte Bedingung erfüllt ist (z. B. „erste Quest abgeschlossen“). Hat Titel, Beschreibung, Icon, Fortschritt, XP-Belohnung und Seltenheit. |
| **Charakter** | Spielfigur eines Spielers mit Benutzername, Avatar, Titel, Level, XP, Gesamt-XP und Skill-Werten. Jeder Spieler hat genau einen Charakter. |
| **Coins** | Spielwährung, die beim Abschluss von Quests und Achievements vergeben und im Reward Shop ausgegeben wird. Coins haben keinen echten Geldwert. |
| **Daily Quest** | Quest, die für einen Tag gilt und zu Beginn jedes Tages neu bereitgestellt wird. |
| **Epic Quest** | Langfristige Quest mit Teilzielen und einer Laufzeit von mehr als einer Woche. |
| **Custom Quest** | Vom Spieler selbst angelegte Quest. |
| **Farming** | Wiederholtes Abschließen derselben einfachen Quest mit dem Ziel, unbegrenzt XP zu sammeln. Das System begrenzt Farming. |
| **Gesamt-XP** | Summe aller jemals erhaltenen XP eines Charakters. Sie sinkt nie. |
| **Gruppen-Challenge** | Zeitlich begrenzte Herausforderung, die mehrere Spieler gemeinsam erfüllen (z. B. „gemeinsam 20 Quests in einer Woche“). |
| **Lebensbereich** | Eine der sieben Kategorien, denen Quests zugeordnet werden: Fitness, Knowledge, Discipline, Career, Creativity, Social, Mental Growth. Synonym: Kategorie. |
| **Level** | Stufe des Charakters, die aus der Gesamt-XP berechnet wird. Die XP für das nächste Level steigen mit jedem Level. |
| **Level-Titel** | Bezeichnung, die einem Levelbereich zugeordnet ist (z. B. Level 10–19: „Apprentice“). |
| **Leaderboard** | Rangliste von Spielern nach XP in einem Zeitraum (z. B. aktuelle Woche). Synonym: Rangliste. |
| **Quest** | Aufgabe aus dem echten Leben, die ein Spieler im System als erledigt markieren kann. Hat Titel, Beschreibung, Art, Lebensbereich, Schwierigkeitsgrad, XP-Belohnung, optional Deadline, Checkliste und Fortschritt sowie einen Status. |
| **Quest-Art** | Daily Quest, Weekly Quest, Epic Quest, Side Quest oder Custom Quest. |
| **Quest-Master** | Systemfunktion, die zu den Zielen eines Spielers passende Quests vorschlägt (zunächst regelbasiert, später optional über eine KI-API). |
| **Quest-Status** | Offen, Erledigt oder Abgelaufen. |
| **Reward Shop** | Bereich, in dem Spieler Coins gegen kosmetische Items eintauschen. |
| **Kosmetisches Item** | Freischaltbarer Gegenstand ohne Einfluss auf XP oder Level: Avatar, Charakterrahmen, Titel, Theme, Profildekoration. |
| **Schwierigkeitsgrad** | Easy, Medium, Hard, Epic oder Legendary; bestimmt die XP-Belohnung einer Quest. |
| **Seltenheit** | Stufe eines Achievements: Common, Rare, Epic oder Legendary. |
| **Side Quest** | Spontane, optionale Quest, die das System vorschlägt. |
| **Skill** | Fortschrittswert eines Charakters in einem Lebensbereich; steigt mit abgeschlossenen Quests dieses Bereichs. |
| **Skill Tree** | Darstellung der Skills mit freischaltbaren Stufen je Lebensbereich. |
| **Spieler** | Angemeldeter Nutzer von SideQuest (ROLE-02). |
| **Streak** | Anzahl aufeinanderfolgender Tage (Daily Streak) bzw. Wochen (Weekly Streak), an denen der Spieler mindestens eine Quest abgeschlossen hat. |
| **Tag** | Kalendertag von 00:00 bis 23:59 Uhr in der Zeitzone des Spielers (siehe ASM-05). |
| **Weekly Quest** | Quest, die innerhalb einer Kalenderwoche (Montag 00:00 bis Sonntag 23:59) erledigt werden muss. |
| **Woche** | Kalenderwoche nach ISO 8601, Montag bis Sonntag. |
| **XP** | Erfahrungspunkte, die ein Spieler für abgeschlossene Quests und Achievements erhält. |
